Troubleshooting

Common issues and their fixes.

"Unable to locate file in Vite manifest"

Front-end assets aren't built. Run a production build (or start the dev server):

npm run build      # production
npm run dev        # development

Blank page / buttons do nothing

Usually means assets failed to load. Rebuild with npm run build, confirm public/build/manifest.json exists, and check the browser console for asset 404s. If you changed .env on production, run php artisan config:cache.

Always redirected to /install

The app considers itself "not installed" when the database isn't reachable or hasn't been migrated. Confirm your DB_* settings and run php artisan migrate. A migrated database (a users table) is auto-detected as installed and writes a storage/installed marker.

Errors show a stack trace

APP_DEBUG=true in production. Set APP_DEBUG=false and APP_ENV=production, then php artisan config:cache. Custom 404/500/503 pages will then be shown instead.

Vapi webhook returns 401

The x-vapi-secret header doesn't match VAPI_SERVER_SECRET. Verify both sides match, and clear cached config (php artisan config:cache). See Webhooks.

AI doesn't answer calls

  • VAPI_PRIVATE_KEY is set and valid.
  • The clinic has a provisioned phone number and a saved AI configuration (Settings → AI Assistant).
  • The Vapi webhook URL points to your public /api/webhooks/vapi and the secret matches.
  • Your Vapi account has call balance.
  • The clinic isn't over its monthly minute limit (inbound calls are declined when exceeded). See Usage metering.

Appointment reminders not sending

The scheduler isn't running. Add the cron entry so schedule:run fires every minute, and make sure a queue worker and SMTP are configured. See Deployment.

* * * * * cd /path/to/app && php artisan schedule:run >> /dev/null 2>&1

Queued work not processing

Start a worker: php artisan queue:work. The default driver is database; ensure the jobs table exists (it ships in migrations).

"This clinic account has been disabled"

A platform admin disabled the clinic. Re-enable it in Platform → Clinics. See Platform Admin.

Stripe checkout returns but no subscription

The webhook may be delayed or misconfigured. The Billing page shows a "finalizing" state and polls; if it never resolves, confirm the Stripe webhook points to /api/webhooks/stripe with the correct signing secret. See Webhooks.

Permission denied writing storage

chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

Still stuck?

Check storage/logs/laravel.log for the underlying error, and review the FAQ.
