Required PHP extensions

Most are bundled with a standard PHP build. The installer verifies each one.

  • pdo & pdo_mysql
  • mbstring
  • openssl
  • tokenizer
  • xml
  • ctype
  • json
  • bcmath
  • fileinfo
  • curl

Writable paths

The web server user must be able to write to:

  • storage/ (and all subdirectories)
  • bootstrap/cache/
  • the project root (to create/update .env during installation)
chmod -R 775 storage bootstrap/cache
# set ownership to your web server user, e.g. www-data
chown -R www-data:www-data storage bootstrap/cache

Production essentials

For a live deployment you should also configure:

  • A queue worker (the project defaults to the database queue driver).
  • A cron entry running Laravel's scheduler every minute (for appointment reminders).
  • HTTPS (required by Stripe and Vapi webhooks).
