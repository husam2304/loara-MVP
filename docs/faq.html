Frequently Asked Questions

Answers to the questions buyers ask most.

Do I need a Vapi account to use Hiro?

You need Vapi only for the AI voice features (answering/placing calls). The dashboard, appointments, patients, providers, analytics, and admin all work without it. Add VAPI_PRIVATE_KEY and configure an assistant to turn voice on. See Vapi Setup.

Do I need Stripe?

Only to charge clinics for subscriptions. You can run and demo the entire app without Stripe; billing screens simply won't process real payments until keys are added. See Billing & Plans.

Can I rebrand it (white-label)?

Yes. Set APP_NAME (or the branding name in Platform → Settings) and it propagates to the whole UI, titles, emails, and landing page. Clinics add their own logo/favicon. No code changes needed. See White-Label & Branding.

Is it really multi-tenant?

Yes. Each clinic is an isolated tenant; records are scoped by clinic_id and access is verified per request. One install serves many clinics, each with its own data, staff, AI assistant, and billing. See Roles & Multi-Tenancy.

Is Hiro HIPAA compliant?

Hiro includes HIPAA-ready features — identity verification before sharing PHI, audit logging, an AI "HIPAA mode" toggle, and access controls. Compliance, however, is an operational responsibility of the operator (BAAs with vendors like Vapi/Stripe, hosting, policies, training). Hiro is a strong foundation, but deploying it does not by itself make your operation HIPAA compliant.

Which license do I need on CodeCanyon?

A Regular License covers a single end product. If you run Hiro as a SaaS charging end users recurring fees to access it, an Extended License is appropriate. Always refer to the current Envato license terms bundled with your purchase (LICENSE.md).

Can I add more payment gateways or integrations?

Yes. Payments go through PaymentGatewayManager — implement the gateway contract to add one. Integration sync has a single extension point (IntegrationSyncService::runProviderSync()) for real provider connectors. See White-Label & Branding.

How do I add a new AI tool?

Register the name in the CallToolName enum and add a handler in VapiToolDispatcher::dispatch(), then sync tools to Vapi. See AI Tools Reference.

What are the demo logins?

After seeding: hiro@mail.com (SuperAdmin) and clinic@mail.com (Enterprise clinic owner). Password for all seeded users is password. See Quick Start.

Does it come with tests?

Yes — an extensive Pest test suite runs on in-memory SQLite via php artisan test.

How do I update after buying a new version?

Replace the files, then run composer install, php artisan migrate --force, rebuild assets, and clear caches. See Deployment.
