Get Started

Configuration

All configuration lives in the .env file. The keys below mirror .env.example. Several services (Stripe, Claim.MD, SMTP) can also be configured from the Platform panel instead of .env.

!

For production set APP_ENV=production and APP_DEBUG=false. With debug enabled, errors expose stack traces to visitors.

Application

KeyDescriptionExample
APP_NAMEProduct/brand name shown across the UI (white-label).Hiro
APP_ENVEnvironment.production
APP_KEYEncryption key — generate with php artisan key:generate.base64:…
APP_DEBUGDebug mode. Must be false in production.false
APP_URLPublic base URL of your install.https://app.example.com

Mail

Used for email verification and appointment reminders. You can also manage SMTP from Platform → Settings.

MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=
MAIL_PASSWORD=
MAIL_FROM_ADDRESS="hello@example.com"
MAIL_FROM_NAME="${APP_NAME}"

Vapi (AI voice agent)

Required for the AI calling features. Keys come from the Vapi dashboard. Full walkthrough in Vapi Setup.

KeyDescription
VAPI_PRIVATE_KEYServer-side API key. Required — the Vapi service throws without it.
VAPI_PUBLIC_KEYClient-side key (safe to expose) for the web call widget.
VAPI_BASE_URLAPI base URL. Default https://api.vapi.ai.
VAPI_SERVER_SECRETShared secret used to verify inbound webhooks (sent as x-vapi-secret).
VAPI_WEBHOOK_URLPublic URL Vapi calls for tools/events — your /api/webhooks/vapi endpoint.

Stripe (billing)

Required for subscriptions and checkout. Keys come from the Stripe dashboard. See Billing & Plans.

PAYMENT_GATEWAY=stripe
STRIPE_KEY=pk_live_…
STRIPE_SECRET=sk_live_…
STRIPE_WEBHOOK_SECRET=whsec_…

Each plan/cycle maps to a Stripe Price ID:

STRIPE_PRICE_STARTER_MONTHLY=
STRIPE_PRICE_STARTER_YEARLY=
STRIPE_PRICE_GROWTH_MONTHLY=
STRIPE_PRICE_GROWTH_YEARLY=
STRIPE_PRICE_PROFESSIONAL_MONTHLY=
STRIPE_PRICE_PROFESSIONAL_YEARLY=
STRIPE_PRICE_ENTERPRISE_MONTHLY=
STRIPE_PRICE_ENTERPRISE_YEARLY=
★

Plans are stored in the database and editable in Platform → Pricing. They can be synced to Stripe from the same screen, which fills these Price IDs for you.

Queue, cache & session

Sensible defaults ship in .env.example. The project uses the database driver for queue, cache, and sessions out of the box, so no Redis is required to get started.

QUEUE_CONNECTION=database
CACHE_STORE=database
SESSION_DRIVER=database

Config files

Application config keys are namespaced under config/. Notable files:

FilePurpose
config/vapi.phpVapi keys, base URL, server secret, webhook URL.
config/subscriptions.phpDefault gateway, trial length, grace period, plan price-ID map.
config/services.phpStripe, Claim.MD, and Stedi credentials.
ℹ

Always reference config values in code via config('…'), never env() outside of config files — environment variables are not available once configuration is cached in production.
