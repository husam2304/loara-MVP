AI Voice Agent

Workflow Builder

Compose a multi-assistant call flow — a Vapi squad — where calls hand off between specialized assistants (front desk, billing, nurse line), then deploy it with one click.

ℹ

The workflow builder requires the custom_workflows plan feature and the clinic_owner role. On lower plans the menu item is hidden and the route redirects to billing.

Concepts

TermMeaning
WorkflowThe squad container for one clinic (SquadWorkflow).
Assistant nodeOne AI assistant in the squad (WorkflowNode): name, role, system prompt, greeting, model, temperature, voice, and the tools it may use.
Entry pointThe node that answers first. Exactly one node is the entry point.
TransitionA directed hand-off between two nodes (WorkflowEdge): a condition, an optional spoken hand-off message, and how much context to pass.

Create a workflow

Open Workflow in the clinic panel. If none exists you'll see an empty state. Enter a name and click Create workflow — a "Front Desk" entry-point node is created automatically, pre-filled from your saved AI assistant configuration.

Add assistants

Click Add assistant and configure:

  • Name & optional role (e.g. "Billing").
  • Greeting and system prompt.
  • Model (gpt-4o, gpt-4o-mini, gpt-3.5-turbo) and temperature (0–1).
  • Voice provider (vapi, elevenlabs, azure) and voice name.
  • Tools — which of the 14 tools this assistant may use.

Use Set entry to change which node answers first, Edit to modify, or Delete (the entry node can't be deleted).

Add transitions

Click Add transition and choose:

  • From and To assistants.
  • When (condition) — e.g. "Caller has a billing question".
  • Hand-off message — spoken as the transfer happens.
  • Context passed — full conversation, recent messages, or start fresh.

Deploy to Vapi

Click Deploy squad. Hiro builds a Vapi squad payload from your nodes and transitions and creates or updates the squad via the API. Validation requires:

  • At least 2 assistant nodes.
  • Exactly one entry-point node.
  • The entry node has at least one outgoing transition.
  • VAPI_PRIVATE_KEY is configured.
  • Your AI assistant configuration has been saved (so function tools exist in Vapi).

On success the clinic switches to squad mode and inbound calls are served the squad. The page shows a Deployed badge.

!

If deployment is blocked, the page shows the exact reason (e.g. "Workflow must have exactly one entry point node" or "Save your AI Assistant configuration first").

Disable squad mode

Click Disable squad to delete the Vapi squad and revert the clinic to a single assistant. The workflow definition is kept so you can redeploy later.
