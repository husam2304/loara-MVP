Get Started

Installation

Install Hiro with the built-in web installer (recommended) or manually with the command line.

Option A — Web installer

The installer walks you through a requirements check, database configuration, and admin-account creation. It writes your .env, runs migrations, optionally seeds demo data, and locks itself when finished.

  1. Upload the files to your server and point the web root at the public/ directory.
  2. Create an empty database and note the host, name, username, and password.
  3. Visit https://your-domain.com/install and complete the wizard:
    • Requirements — verifies PHP version, extensions, and writable paths.
    • Database — enter your app name, URL, and DB credentials; the connection is tested before saving.
    • Admin — create the SuperAdmin account; migrations run and demo data is seeded if you opt in.
    • Done — the installer is locked.
ℹ

After completion, a storage/installed marker file is written and the installer redirects away. Delete that file if you ever need to re-run the wizard.

Option B — Manual installation

  1. Copy the environment file and fill in your values (see Configuration): 
    cp .env.example .env
  2. Install PHP dependencies: 
    composer install --no-dev --optimize-autoloader
  3. Generate the application key: 
    php artisan key:generate
  4. Run migrations (add --seed to load demo data): 
    php artisan migrate --seed
  5. Install & build the front-end: 
    npm install
npm run build
★

A migrated database is automatically detected as "installed", so a manual install will not redirect you back into the web installer.

Local development

For local work, a single command runs the PHP server, queue worker, log viewer, and Vite dev server together:

composer run dev

Or run the Vite dev server on its own:

npm run dev
!

If a UI change does not appear, rebuild assets with npm run build (production) or ensure npm run dev is running (development).

Verify the install

  1. Open your site — you should reach the login page.
  2. Log in with the seeded SuperAdmin: hiro@mail.com / password.
  3. Continue to the Quick Start.

Run the test suite (optional)

Hiro ships with an extensive Pest test suite that runs on an in-memory SQLite database:

php artisan test --compact
