AI Voice Agent

Vapi Setup

Connect your Vapi account so the AI agent can answer and place calls. This is required for all voice features.

1. Get your Vapi keys

Create an account at dashboard.vapi.ai and copy your keys. Add them to .env:

VAPI_PRIVATE_KEY=your-private-key
VAPI_PUBLIC_KEY=your-public-key
VAPI_BASE_URL=https://api.vapi.ai
VAPI_SERVER_SECRET=a-long-random-string
VAPI_WEBHOOK_URL=https://your-domain.com/api/webhooks/vapi
KeyRole
VAPI_PRIVATE_KEYServer key for the REST client (create assistants, phone numbers, squads). Required.
VAPI_PUBLIC_KEYClient key for the in-browser web call widget. Safe to expose.
VAPI_SERVER_SECRETShared secret you choose; Vapi sends it as the x-vapi-secret header so Hiro can verify webhooks.
VAPI_WEBHOOK_URLPublic URL of your Vapi webhook endpoint.
!

Keep VAPI_PRIVATE_KEY secret — it is never sent to the browser. The VapiService constructor throws if it is missing.

2. Configure the assistant

In the clinic panel, go to Settings → AI Assistant. Here you configure how the agent behaves:

  • Model provider & model, temperature, confidence threshold.
  • Voice provider, voice, and speaking rate.
  • Greeting message, after-hours message, and system prompt.
  • Behavior toggles: sentiment analysis, auto-escalation, recording, voicemail detection, HIPAA mode, interruptions.

Saving syncs the assistant and its function tools to Vapi via VapiService.

3. Provision a phone number

From the same screen, provision a Vapi phone number for the clinic. Inbound calls to that number are routed to the clinic's assistant. The number's status, SIP URI, and provider are stored on the clinic's AI configuration.

ℹ

Your Vapi account must have call balance/credits for the assistant to answer live calls.

4. Point Vapi at the webhook

Hiro exposes a single Vapi webhook:

POST https://your-domain.com/api/webhooks/vapi

Every request is verified against VAPI_SERVER_SECRET using the x-vapi-secret header; mismatches are rejected with 401. It handles these Vapi message types:

Message typeWhat Hiro does
assistant-requestReturns the clinic's assistant or squad (and enforces minute limits).
tool-callsDispatches each tool and returns results.
status-updateUpdates the call's lifecycle status.
transcriptStores transcript lines (deduplicated).
end-of-call-reportStores duration, cost, sentiment, summary, recording; records usage.

See Webhooks for full payload handling.

5. Local development tunnel

Vapi must reach your machine to deliver webhooks. Use a tunnel (e.g. Expose or ngrok), then push the current tunnel URL — plus the latest tools and system prompt — to all your Vapi assistants:

php artisan vapi:sync-tunnel

This rewrites the assistants' server URLs to your tunnel so tool calls and events arrive locally.

Multi-assistant flows

For call routing across several specialized assistants (e.g. front desk → billing → nurse), use the Workflow Builder to compose a Vapi squad and deploy it.
