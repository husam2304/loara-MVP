Features

Insurance

Verify patient insurance eligibility and submit claims through swappable clearinghouse gateways. Available in the clinic panel at /insurance.

Gateways

InsuranceVerificationManager fronts pluggable gateways so you can switch clearinghouses without changing the rest of the app:

GatewayUseCredentials
Claim.MDEligibility & claim submissionCLAIMMD_API_KEY (or via Platform → Settings)
StediEligibilitySTEDI_API_KEY, STEDI_BASE_URL

The Claim.MD gateway resolves its API key from the Platform-managed gateway configuration first, then falls back to config/services.php.

Eligibility verification

From the Insurance screen, run an eligibility check for a patient's policy. The request is sent to the active gateway, which returns coverage status and plan details. The AI agent can also trigger this during a call via the verify_insurance tool (after the caller is verified).

Claims

  • Submit a claim — POST /insurance/{claim}/submit sends the claim to the gateway and stores the returned claim ID and status.
  • Check status — GET /insurance/{claim}/status re-queries the gateway.
  • Payer list — GET /insurance/payers returns supported payers.

Prior authorizations

The Insurance screen lists prior authorizations alongside eligibility and claims so front-desk staff have a single place to manage payer interactions.

ℹ

Insurance features require a clearinghouse account and API key. Without one, the rest of Hiro (calls, appointments, patients) is unaffected — the module simply has no gateway to call.

Configuration

Set credentials in .env:

CLAIMMD_API_KEY=your-claim-md-key
STEDI_API_KEY=your-stedi-key
STEDI_BASE_URL=https://healthcare.stedi.com

Or manage the Claim.MD key from Platform → Settings → Claim.MD, where you can also test the connection.
