AI Voice Agent Overview

The AI agent is Hiro's core. It answers clinic calls through Vapi and performs front-desk tasks using clinic-scoped server-side tools, escalating to a human when needed.

End-to-end flow

  1. A call arrives on the clinic's Vapi phone number (or a web/chat session starts).
  2. Vapi serves the assistant — for inbound calls it asks Hiro which assistant/squad to use via the assistant-request webhook.
  3. The AI uses tools — during the conversation Vapi posts tool-calls to Hiro's webhook. Each call is dispatched by VapiToolDispatcher to a handler.
  4. Hiro responds with a result the assistant reads back to the caller.
  5. The call is recorded — status updates, transcript lines, recording, summary, sentiment, and AI confidence are stored, then surfaced in the Call Center.

Server-side tools

Tools are the actions the AI can take. Each tool is clinic-scoped and returns a structured { success, result, data } payload. There are 14 tools — see the full AI Tools Reference. Examples: lookup_patient, book_appointment, verify_insurance, assess_urgency, transfer_call.

Identity verification

Protected tools (those that read or change patient data) require the caller's identity to be verified first. Verification happens by confirming the patient's date of birth — via lookup_patient (when a matching DOB is supplied) or verify_identity. A caller cannot act on a record simply by naming a patient ID.

!

This applies to web/chat sessions too: a passed patient_id alone never grants access. The DOB confirmation is always required, protecting patient health information (PHI).

Details in AI Tools Reference → Verification gate.

Failure handling & escalation

If a tool fails, the failure is recorded on the call. After two consecutive failures, the agent offers to transfer the caller to a staff member. The transfer_call tool records a high-priority callback task and informs the caller, so nothing is dropped.

Inbound vs. outbound

DirectionHow it starts
InboundPatient calls the clinic's Vapi number; Vapi requests the assistant from Hiro.
OutboundStaff trigger single or batch calls from the Call Center (reminders, follow-ups).
Web / chatBrowser-based session using the Vapi public key.

Usage enforcement

Each plan includes a monthly call-minute allowance. Usage is metered per call. Outbound calls are blocked when the limit is exceeded, and inbound calls are declined at the assistant-request step for clinics over their limit (Enterprise plans are unlimited). See Billing & Plans → Usage metering.

What gets stored per call

  • Status, direction, caller phone/name, start/answer/end timestamps, end reason.
  • Duration, cost, sentiment, AI confidence score, and a summary.
  • Line-by-line transcript and a recording URL (when provided by Vapi).
  • Every tool invocation with its input/output, duration, and success flag.
